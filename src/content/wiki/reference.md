# Image Vault

_Last reviewed: 2026-04-05_

Browse and manage **reference images** — the visual library used across ARCS.

## Navigation map vault

- Scrollable **main** region (hub allows vertical scroll unlike Character / Writer internals).
- Filters, grids, and detail views depend on your Supabase **vault** configuration; when not configured, fallbacks may use local storage per product notes.

## Tools & functions

- Search / filter collections (when backend available).
- Open items into studios or storyline where integration buttons exist.
