# Assets Studio

_Last reviewed: 2026-04-05_

**Props, environments, and non-character** reference libraries — parallel workflow to Character Studio with Asset Studio styling.

## Navigation map

- **Purple / amethyst** chrome with gold metallic accents on primary buttons.
- **Library panels** for collections; **save to vault** flows when Supabase is configured.

## Tools & functions

- Asset **albums** and **generations** with reference-driven prompts.
- **Promote / import** bridges from Storyline or other portals (see buttons in header when data is available).

## Customization

- Theme family **purple** while active.
